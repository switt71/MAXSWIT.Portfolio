# 🌐 Portfolio - Swit Wongsing (Maxswit)

เว็บไซต์ Portfolio ส่วนตัวสำหรับนักศึกษาสาขาสื่อนฤมิต (Creative Media) ในรูปแบบ Modern Dark & Neon Green (Glassmorphism & Gradient)

---

## 🚀 ฟีเจอร์หลัก (Features)
- **Modern Dark & Neon Green Theme:** ธีมสีดำตัดเขียวนีออน สไตล์ Glassmorphism และ Gradient สวยงาม ทันสมัย
- **Responsive Design:** รองรับการแสดงผลทุกหน้าจอ ทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
- **Interactive Components:** ฟังก์ชันกรองผลงาน (Portfolio Filter), ป๊อปอัปดูรายละเอียด (Modal Preview), ปุ่ม Back to Top และฟอร์มติดต่อ
- **Global Footer Management:** จัดการและแก้ไขข้อมูล Footer และ Social Media ได้จากจุดเดียวผ่านไฟล์ `assets/js/main.js`

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **Bootstrap 5.3.3**
- **Google Fonts** (Plus Jakarta Sans & Prompt)
- **Font Awesome 6.5.2**

---

## 📁 โครงสร้างหน้าเว็บ (Pages)
- `index.html` - หน้าแรก แนะนำตัว ทักษะความเชี่ยวชาญ และพรีวิวผลงาน (Home)
- `education.html` - ประวัติการศึกษาทุกระดับ ตั้งแต่อนุบาลถึงระดับอุดมศึกษา (Education)
- `portfolio.html` - คลังผลงานสื่อนฤมิต 3D, Game, Motion Graphics, UI/UX (Portfolio)
- `activity.html` - กิจกรรมการอบรม การแข่งขัน และสัมมนา (Activity)
- `contact.html` - ข้อมูลการติดต่อ โซเชียลมีเดีย และแบบฟอร์มส่งข้อความ (Contact)

---

## 💻 วิธีการเปิดใช้งาน (How to Run)
สามารถเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ใดก็ได้ (Chrome, Edge, Safari, Firefox) โดยไม่ต้องติดตั้ง Server เพิ่มเติม
